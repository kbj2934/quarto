# 🎲 QUARTO AI Tutorial Showcase

같은 **콰르토(Quarto) 보드게임 튜토리얼**을 여러 생성형 AI로 제작하고,  
각 AI가 만들어 낸 결과물의 **UI, 학습 흐름, 기능 구성, 게임 설계 차이**를 비교하기 위한 프로젝트입니다.

## 🌐 작품 보기

GitHub Pages를 활성화하면 `index.html`에서 4개의 작품을 한눈에 비교하고 각각 실행할 수 있습니다.

---

## 🤖 생성형 AI별 작품

### 1. Gemini

**파일:** `gemini.html`

- 4단계 중심의 간결한 튜토리얼
- 콰르토 말의 4가지 속성 학습
- 승리 조건 직접 체험
- 상대에게 안전한 말을 건네는 전략 학습
- 튜토리얼 이후 **AI 대전 / 2인 로컬 대전** 지원
- 어두운 배경과 입체적인 보드게임 UI

### 2. ChatGPT

**파일:** `chatgpt.html`

- 처음 사용하는 학생도 쉽게 접근할 수 있는 소개형 시작 화면
- 약 **5분 분량의 단계형 튜토리얼**
- 말의 특징 → 말 건네기 → 배치 → 콰르토 선언 순으로 학습
- 튜토리얼 완료 후 **컴퓨터 대전 / 친구와 대국** 가능
- 밝은 원목 보드와 친근한 교육용 UI

### 3. penGPT - Claude

**파일:** `pengpt-claude.html`

- 총 **7단계 학습 과정**
- 규칙 설명뿐 아니라 실전 연습과 퍼즐 중심 구성
- 위험한 말과 이길 수 있는 칸을 보여주는 도움말
- 도전 퍼즐 제공
- 컴퓨터 난이도 조절
- **2×2 고급 규칙**, 콰르토 선언 규칙 설정 가능
- 컴퓨터 대전과 2인 대전 지원

### 4. Claude

**파일:** `claude.html`

- 여러 학습 활동을 세분화한 챕터형 튜토리얼
- 조각 관찰과 속성 분류
- 승리 가능한 10개 줄 확인
- 말 놓기 → 상대에게 말 건네기 순서 반복 연습
- 위험한 말 판단 활동
- 한 번에 이기기, 상대 막기 등 전략 문제
- 실전 AI 대국까지 연결
- 짙은 게임 매트와 원목 말을 활용한 보드게임 스타일 UI

## ▶️ 실행 방법

별도의 설치 과정은 필요하지 않습니다.

1. 저장소를 다운로드하거나 Clone 합니다.
2. `index.html`을 웹 브라우저에서 엽니다.
3. 원하는 생성형 AI의 작품을 선택합니다.

대부분의 기능은 HTML, CSS, JavaScript만으로 동작하도록 제작되어 있습니다.

---

## 🚀 GitHub Pages로 배포하기

1. GitHub 저장소에 모든 파일을 업로드합니다.
2. 저장소의 **Settings**로 이동합니다.
3. **Pages** 메뉴를 선택합니다.
4. `Build and deployment`에서 **Deploy from a branch**를 선택합니다.
5. Branch를 `main`, Folder를 `/ (root)`로 설정합니다.
6. **Save**를 누릅니다.

설정 후 생성된 GitHub Pages 주소를 통해 웹에서 바로 실행할 수 있습니다.

## 🧩 Quarto란?

콰르토는 16개의 말을 사용하는 4×4 전략 보드게임입니다.

각 말은 다음 4가지 속성을 가집니다.

- 밝은색 / 어두운색
- 원형 / 사각형
- 높은 말 / 낮은 말
- 윗면에 구멍 있음 / 없음

가로, 세로 또는 대각선 한 줄의 네 말이  
**하나 이상의 공통 속성**을 가지면 콰르토가 완성됩니다.

특히 일반적인 보드게임과 달리  
**내가 놓을 말을 상대방이 골라 준다**는 점이 핵심입니다.
